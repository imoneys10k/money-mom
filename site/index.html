Money Mom 是装进 AI agent 的记账能力。说一句话，或丢一个账单，它帮你记账、查账、对账。AI 只负责听懂你的话，账由程序来记、来校验。 Money Mom is a bookkeeping skill for AI agents. Say a sentence or drop in a statement, and it records, queries and reconciles. The AI only understands you; a program keeps and checks the books.

为什么可信Why you can trust it

AI 负责听懂，程序负责记对。The AI understands. A program gets it right.

让 AI 直接改账本不可靠。所以 Money Mom 把“理解”和“记账”分开：每一步都有程序把关，每一笔都可追溯。Letting an AI edit a ledger directly is unreliable. Money Mom separates understanding from bookkeeping: a program guards every step, and every entry can be traced.

复式记账Double-entry

每笔钱都记“从哪来、到哪去”，每个币种必须恰好平衡，否则整笔拒绝。Every amount records where it came from and where it went. Each currency must balance exactly, or the entry is refused.

AI 不直接写账The AI never writes the books

AI 只说“花了 38，从支付宝，买咖啡”。借贷方向、校验和写入由程序完成。The AI says “spent 38, from Alipay, on coffee”. Direction, checks and writing are done by a program.

只追加，不改历史Append-only

记错了不擦掉，而是作废并重记。来源、置信度、谁写的，都留着。A mistake is voided and re-recorded, never erased. Source, confidence and author are always kept.

从不靠猜Never guesses

含糊的账户名整笔记为“待确认”，并列出候选。AI 的置信度低于 0.9 也先等你确认。A vague account name makes the entry pending, with candidates listed. An AI confidence below 0.9 also waits for you.

对账后锁定Locked once reconciled

核对过银行余额的时期被锁定，回头改只能由你本人写明原因。A period checked against the bank is locked. Changing it takes you, in person, with a written reason.

本地优先Local-first

数据留在你的电脑上，是人能读的纯文本。程序默认不联网、没有运行时依赖；只有你主动取汇率时才联网。Your data stays on your machine as readable text. The program does not use the network by default and has no runtime dependencies; only fetching rates, which you run yourself, goes online.

账单与对账Statements and reconciliation

账单交给它，核对也交给它。Hand it the statement. It checks the books.

每家银行的导出格式都不同，所以只描述一次，之后每月按同样的方式处理。没有内置的银行预设：格式常变，没有真实样本的预设就是编造；支付宝、微信有未经验证的映射草案可作起点。Every bank exports a different layout, so you describe it once and it is applied the same way every month. There are no built-in bank presets: layouts change, and a preset without real samples would be made up. Alipay and WeChat have unverified draft mappings as a starting point.

一份映射，每月适用One mapping, every month

import inspect 探测编码、表头和各列含义；日期是日/月先后、哪个符号代表收入这类含糊处会问你，不替你决定。重复导入只跳过已有的行。import inspect finds the encoding, header and columns, and asks about what it cannot know: day-first or month-first dates, which sign means money in. Re-importing only skips rows already there.

问一次，学一次Ask once, learn once

没有规则命中的行先待确认，按对方分组。你回答一次，就写成规则，等着的历史行一并补全。Rows no rule matched wait as pending, grouped by payee. One answer becomes a rule, and the waiting history is settled with it.

逐笔对账Line by line

找出漏记、多记、金额不符，以及可能被扣了两次的款项，再核对期末余额。只有全部对上才封存并锁定该期间。Finds missing and extra entries, amounts that disagree and charges that may have been taken twice, then checks the closing balance. Only a full match is sealed and the period locked.

money-mom import run alipay.csv --map alipay --account 支付宝
money-mom import rule-add --map alipay --match 美团 --account 外卖
money-mom reconcile 银行卡 cmb.csv --map cmb --closing-from-statement --assert
多币种Many currencies

不必固定一个币种。Not tied to one currency.

美元、港币、人民币混着用也没关系：币种能认出来，认不出来就问你，折算可以一直追溯到汇率的来源。Dollars, Hong Kong dollars and yuan side by side are fine: the currency is recognised, asked about when unclear, and every conversion traces back to where its rate came from.

认得出币种Recognises the currency

5美元、HK$200、USD 5、1,200元都行。遇到有歧义的 $ 和 ¥，先看账户，再看账本；还不确定就问你，从不靠猜。5 USD, HK$200, 5美元 or 1,200元 all work. For an ambiguous $ or ¥ the accounts decide first, then your ledger; if it is still unclear it asks, and never guesses.

换汇与折算Exchange and conversion

exchange 记下你实际成交的汇率；networth 把所有币种折成一个总额。缺汇率的币种会明确列出，不会悄悄丢掉。exchange keeps the rate you actually got; networth turns every currency into one total. A currency with no rate is listed, never silently dropped.

联网只在你开口时Online only when you ask

rates update 取欧洲央行的每日参考汇率，只发送币种代码和日期。汇率连同来源存进账本，之后折算完全离线。这不是实时行情。rates update fetches the ECB's daily reference rates and sends only currency codes and a date. Each rate is stored with its source, so conversion afterwards is fully offline. It is not a live feed.

money-mom exchange 100 USD 720 CNY --from 美元户 --to 银行卡
money-mom rates update
money-mom networth
