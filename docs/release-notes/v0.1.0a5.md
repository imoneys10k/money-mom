## 新增 · What is new

- **跨来源防重复 · Duplicates across sources**：`money-mom dupes`。微信账单和银行账单、或你对 AI 说的话和账单里各出现一次的同一笔支付，程序找出候选并附证据（账单行上的支付方式指向另一条的账户、对方或说明相同、同日同账户），**由你判断**是不是同一笔：`dupes resolve ID1 ID2 --same --keep ID` 作废另一条（不删除），`--different` 记住以后不再问。AI 必须转述你的回答，否则命令拒绝。 / Candidates with evidence, and **you decide**. "Same" voids the other entry (nothing is deleted); "different" is remembered. An AI must relay your answer or the command is refused.
- **导入时先挂起 · Held on import**：账单行若像是账本里已有的一笔，先记成待确认，不计入任何余额，等你回答；作废的行再导入同一份账单也不会回来。 / A statement row that looks like an existing entry is held as pending, in no balance, until you answer; a voided row does not return on re-import.
- **防篡改 · Tamper-evident**：每个事件带着它之前所有事件的哈希；`money-mom verify`（`check` 与 `doctor` 里也有）找出被改过、删掉或手工塞入的事件，并打印链头，你可以另存一份。这是发现不是阻止，也发现不了重算所有哈希的改写。 / Each event carries a hash of everything before it; `verify` finds an event edited, removed or added by hand and prints the chain head. Detection, not prevention.
- **直接导入 .xlsx · `.xlsx` statements**：微信支付默认导出的就是 .xlsx，不用再另存为 CSV；标准库实现，没有新依赖。 / WeChat Pay exports `.xlsx`; it is now read directly, with the standard library only.
- **微信映射 · WeChat mapping**：用一份真实导出核对过（仅此一份）；默认跳过银行卡付款的行，避免与银行账单重复。映射的 `[[skip]]` 支持 `regex`。 / Checked against one real export; skips rows paid by a bank card to avoid double counting with the bank statement. `[[skip]]` accepts a `regex`.
- 测试 575 个，另有对每条新规则的变异测试。 / 575 tests, plus mutation checks of every new rule.

## 已知限制 · Known limitations

- 自己账户之间的转账（两份账单上各出现一次）还不会被识别为重复 · A transfer between your own accounts that shows on both statements is not yet recognised as one
- 哈希链只能发现改动，不能阻止；重算了此后所有哈希的改写发现不了 · The hash chain detects, it does not prevent; a rewrite that recomputes every later hash is not caught
- 支付宝映射仍是未经真实导出验证的草案；微信映射只核对过一份导出 · The Alipay mapping is still an unverified draft; the WeChat one was checked against a single export
- 没有内置银行预设；各 agent 内的对话效果还没有逐一实测 · No built-in bank presets; behaviour inside each agent has not been tested one by one
