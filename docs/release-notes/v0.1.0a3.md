## 新增 · What is new

- **账单导入 · Statement import**：`money-mom import`。用一份映射文件（TOML）描述一种 CSV 的编码、表头行、列、日期格式、正负号约定和分类规则，之后每次都按同样的方式处理。`import inspect` 探测并给出建议，日期是日/月先后、哪个符号代表收入这类含糊处不替你决定；没有规则命中的行先待确认并按对方分组，回答一次就写成规则（`rule-add`），`recheck` 补全等着的历史行。重复导入安全，整批全有或全无，被拒绝的行按账单行号指出。**没有内置的银行预设**：格式常变，没有真实样本的预设就是编造。 / Describe a CSV layout once in a mapping file and it is applied the same way every time. `inspect` suggests a mapping and asks about what it cannot know; unmatched rows wait as pending grouped by payee, and one answer becomes a rule. Re-imports are safe, batches all-or-nothing. There are **no built-in bank presets**: layouts change and a preset without real samples would be made up.
- **对账 · Reconciliation**：`money-mom reconcile`。逐笔比对账单和账本，找出漏记、多记、金额不符和疑似重复扣款，核对期末余额；只有完全对上才允许 `--assert` 封存并锁定该期间。PDF 账单由 agent 读取后以 JSON 提交。 / Compares a statement with the ledger line by line: missing and extra entries, amounts that disagree, possible double charges, and the closing balance. Only a fully matching result may be sealed with `--assert`, which locks the period. A PDF is read by the agent and passed in as JSON.
- **PyPI 与 npm · PyPI and npm**：`pip install` / `uv tool install "money-mom==0.1.0a3"`，或者直接 `npx money-mom doctor`（npm 包只是一个启动器，通过 uv 运行同版本的引擎，自己不安装任何东西）。 / Install the engine from PyPI, or run `npx money-mom doctor`: the npm package is only a launcher that runs the same engine version through uv and installs nothing itself.
- 测试 367 个；文档里写的每条命令、TOML 和批量示例都有测试保证真实可用。 / 367 tests, and every command, TOML mapping and batch example in the docs is checked against the real program.

## 联网 · The network

程序仍然只有一个会联网的命令：`money-mom rates update`（取汇率，只发送币种代码和日期）。npm 启动器第一次运行时，`uvx` 会从 PyPI 下载引擎。 · Still only one command uses the network: `money-mom rates update`. On first run the npm launcher lets `uvx` download the engine from PyPI.

## 已知限制 · Known limitations

- 没有内置的支付宝、微信预设，需要用 `import inspect` 和你自己的导出文件写映射 · No built-in Alipay or WeChat presets: write the mapping from your own export with `import inspect`
- 对账只处理一个账户、一个币种的账单；PDF 靠 agent 读取，可能读错，所以期末余额要核对 · Reconciliation covers one account and one currency at a time; a PDF is read by the agent and can be misread, so check the closing balance
- 还没有月报、订阅与异常提醒、投资者包（持仓与成本） · No monthly report, subscription alerts or investor pack (holdings, cost basis) yet
- 各 agent 里的对话效果尚未逐一实测 · Conversation behaviour is not yet tested in every agent
