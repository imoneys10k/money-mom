## 新增 · What is new

- **月报 · Monthly report**：`money-mom report`。收入、支出、结余与储蓄率，分类占比及与上月的变化，最大几笔支出，净资产月初到月末的变化。待确认不计入，转账与换汇不算收支，缺汇率时标记不完整，没有上月数据时对比为空而不是 0。 / Income, spending, net and savings rate, categories with change from last month, the biggest items, and the net worth change. Pending entries are not counted, transfers and exchanges are not spending, a missing rate marks the figures partial, and no previous month means no comparison, never a zero.
- **图表 · Charts**：`money-mom chart`。一页 HTML 简报或单张 SVG：支出构成、分类环比、收支趋势、净资产、从收入到结余。投研报告风格，自动跟随深色模式，可打印；`--hide-amounts` 重画一份没有任何金额的版本，方便分享。输出是静态文件：没有脚本、字体或外部资源，不联网。 / A one-page HTML sheet or a single SVG, in the style of a research note, following dark mode and printable. `--hide-amounts` redraws a version with no amounts, safe to share. Static files: no script, no web font, no external resource, no network.
- **订阅与异常提醒 · Subscriptions and alerts**：`money-mom alerts`。识别每周、每月、每年的周期扣款，并给出五种提醒：涨价或降价、该扣没扣、单笔异常大、分类飙升、疑似重复扣款。每条带交易 ID 和触发的规则；证据不足（记录不满三个月、没有填对方）就明确说明，而不是硬判。只提醒，不替你决定。 / Recognises weekly, monthly and yearly recurring charges and raises five kinds of alert, each with entry IDs and the rule that fired. With too little history, or no payee, it says so instead of guessing. It points things out and decides nothing.
- **账单导入 · Statement import**：`money-mom import`，用一份 TOML 映射描述一种 CSV，之后每次都按同样的方式处理；没有内置银行预设。 / Describe a CSV layout once in a mapping; there are no built-in bank presets.
- **对账 · Reconciliation**：`money-mom reconcile`。逐笔比对账单和账本，找出漏记、多记、金额不符和疑似重复扣款，核对期末余额；只有完全对上才允许 `--assert` 封存。 / Line-by-line comparison with a statement; only a fully matching result may be sealed with `--assert`.
- **PyPI 与 npm · PyPI and npm**：`uv tool install "money-mom==0.1.0a4"`，或者 `npx money-mom doctor`（npm 启动器稍后单独发布；它只是通过 uv 运行同版本的引擎）。 / Install from PyPI. The npm launcher will follow separately; it only runs the same engine version through uv.
- 测试 497 个；文档里写的每条命令、TOML 和批量示例都有测试保证真实可用。 / 497 tests, and every command and example in the docs is checked against the real program.

## 已知限制 · Known limitations

- 没有内置的支付宝、微信预设，需要用 `import inspect` 和你自己的导出文件写映射 · No built-in Alipay or WeChat presets: write the mapping from your own export with `import inspect`
- 订阅按“对方”识别，手动记账不填对方就识别不到；记录不满三个月时不会判断 · Recurring charges are recognised by payee: entries without one are invisible to it, and under three months of history nothing is judged
- 对账只处理一个账户、一个币种的账单；PDF 靠 agent 读取，可能读错，所以期末余额要核对 · Reconciliation covers one account and one currency at a time; a PDF is read by the agent and can be misread, so check the closing balance
- 还没有“妈妈”语气档位、投资者包（持仓与成本） · No "Mom" tone levels or investor pack (holdings, cost basis) yet
- 各 agent 里的对话效果尚未逐一实测 · Conversation behaviour is not yet tested in every agent
