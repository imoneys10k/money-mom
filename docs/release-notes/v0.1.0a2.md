## 新增 · What is new

- **币种识别 · Currency recognition**：金额可以直接带币种：`5美元`、`'HK$200'`、`'USD 5'`、`1,200元`。`$`、`¥` 这类有歧义的符号**从不靠猜**：先看账户允许的币种，再看账本里在用的币种；非本位币的推断会先记为待确认，仍不确定就报错并列出候选。`money-mom currency` 可以预览识别结果。 / Write the currency with the amount. Ambiguous symbols like `$` and `¥` are **never guessed**: the accounts decide first, then the currencies in your ledger; a non-base pick waits for confirmation; anything still unclear is an error listing candidates.
- **换汇 · Exchange**：`money-mom exchange 100 USD 720 CNY --from 美元户 --to 银行卡`，记下你实际成交的汇率，每个币种各自仍然平衡。 / Records the rate you actually got; each currency still balances on its own.
- **汇率与折算 · Rates and conversion**：`money-mom rates update` 取欧洲央行每日参考汇率；`money-mom networth` 和 `balance --account Assets --in CNY` 把多币种折成一个总额。汇率连同来源存进账本，折算只用已存的汇率；缺汇率的币种会明确列出，超过 7 天的汇率标为过期。 / Fetch the ECB's daily reference rates; convert many currencies into one total. Rates are stored with their source; a currency with no rate is listed, rates older than 7 days are flagged.

## 联网变化 · The network, honestly

**之前程序完全不联网；现在 `money-mom rates update` 是唯一会联网的命令。** 它必须由你或 agent 显式运行，请求里只有币种代码和日期，不含任何金额或账户；取数失败时一个都不写。来源（Frankfurter，转发欧洲央行数据）每个工作日一次、约 30 种货币、**不含台币**，**不是实时行情**。其余命令仍然离线。 / Until now the program never used the network. `rates update` is now the only command that does: you or your agent run it explicitly, it sends only currency codes and a date (never an amount or an account), and a failure writes nothing. The source republishes the ECB's rates: one per business day, about 30 currencies, **no TWD**, **not a live feed**. Everything else stays offline.

## 升级 · Upgrading

对你的 AI agent 说同样的安装那句话即可；账本**不需要迁移**。旧账本没有 `Equity:汇兑`，要用换汇需先 `money-mom open Equity:汇兑`。 / Say the same install sentence to your agent; the ledger needs **no migration**. Older ledgers lack the conversion account: run `money-mom open Equity:汇兑` once before using `exchange`.

```text
请阅读 https://github.com/imoneys10k/money-mom/blob/main/INSTALL.md 并按说明为我安装 Money Mom。
```

## 已知限制 · Known limitations

- 台币等汇率来源不覆盖的币种，需要用 `rates set` 手动记录（必须写来源） · Currencies the source does not cover (such as TWD) need `rates set`, with a source
- 汇兑损益、持仓与成本还没有（投资者包） · No realised exchange gains, holdings or cost basis yet (investor pack)
- 还没有对账、账单导入、月报 · Still no reconciliation helpers, statement import or monthly report
- 安装器已在隔离环境验证，但**还没有在每个 agent 里逐一实测对话效果** · The installer is verified in isolation, but conversation behaviour is **not yet tested in every agent**
