## 包含什么 · What is in it

- 账本内核：复式记账、只追加、对账后锁定、跨进程文件锁 · Ledger core: double-entry, append-only, locking after reconciliation, cross-process file lock
- 命令行 `money-mom` 与 SQLite 只读查账 · The `money-mom` CLI and read-only SQL queries
- 意图层 `spend` / `income` / `transfer`：名字不确定不猜，记为待确认并列出候选 · Intents that never guess: unsure names become pending, with candidates
- 中文与英文账户树模板、别名、`doctor` · Chinese and English account templates, aliases, `doctor`
- agent 记账必须带置信度，低于 0.9 不能直接入账 · Agents must state a confidence; below 0.9 cannot post directly
- `skills/money-mom`：符合 [Agent Skills](https://agentskills.io) 标准，通过官方校验器 · A skill that follows the Agent Skills standard and passes its validator

189 个测试，在 Linux、macOS、Windows × Python 3.11–3.13 上通过。 · 189 tests, passing on Linux, macOS and Windows × Python 3.11–3.13.

## 已知限制 · Known limitations

- 还没有对账、账单导入、月报、投资者功能 · No reconciliation helpers, statement import, monthly report or investor features yet
- 安装器已在隔离环境验证，但**还没有在每个 agent 里逐一实测对话效果** · The installer is verified in an isolated environment, but conversation behaviour is **not yet tested in every agent**
- 没有退款、借出还款、跨币种转账的专用命令（可用 `add --posting`） · No dedicated refund, lending or cross-currency commands yet (use `add --posting`)
- 账本每次写入都会重放全部事件；个人账本（几万条以内）没问题，更大时会变慢 · Every write replays the whole ledger: fine for personal ledgers (tens of thousands of entries), slower beyond that
- Windows 的文件锁路径已在 CI 通过，但没有在真实的 Windows 机器上长期使用过 · The Windows lock path passes CI but has not seen long real-world use

完整变更见 [CHANGELOG](https://github.com/imoneys10k/money-mom/blob/main/CHANGELOG.md)。
